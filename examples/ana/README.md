# Primjer: Ana

Ana se brine o četiri prostorije s temperaturnim senzorima. Svaki senzor svaki dan sprema jednu datoteku, pa se od posljednjeg izvještaja skupilo 40 datoteka (4 prostorije, 10 dana). Svakog ponedjeljka šef je pita: je li bilo nešto neobično? Ana je dosad svih 40 datoteka otvarala ručno.

Upiši „isprobaj primjer Ana“ i gledaj što agent radi. Zatim ga pitaj: „Koliko si redaka pročitao i je li išta neobično?“ U podacima su skrivena dva problema.

Svi su podaci izmišljeni.
